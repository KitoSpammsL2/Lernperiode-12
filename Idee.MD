Rätsel 1 – Zahlenschloss

Der Spieler muss einen Code mit vier Zahlen finden.


Der Spieler findet ein Zahlenschloss.
Er muss einen Code eingeben.
Im Raum gibt es vier Farben.
Mit dem Glitch-Modus sieht er die Zahlen bei den Farben.
Er gibt die Zahlen in der richtigen Reihenfolge ein.

Hinweise:
Rot = 4
Blau = 1
Grün = 7
Gelb = 3

Lösung: 4173

Wenn der Code richtig ist, ist das Rätsel gelöst. Wenn er falsch ist, kann man es nochmals versuchen.

Rätsel 2 – Symbole

Der Spieler muss drei Symbole richtig anklicken.

So geht es:

Der Spieler sieht drei Symbole auf einem Bildschirm.
Es gibt ein Quadrat, ein Dreieck und einen Kreis.
Er muss die Symbole in der richtigen Reihenfolge anklicken.
Mit dem Glitch-Modus sieht er die richtige Reihenfolge.

Hinweise:

Quadrat = 1
Dreieck = 2
Kreis = 3

Lösung: Quadrat → Dreieck → Kreis

Rätsel 3 – Schalter

Der Spieler muss drei Schalter richtig einstellen.

Der Spieler findet drei Schalter.
Die Schalter heissen A, B und C.
Zwei Schalter müssen eingeschaltet sein.
Mit dem Glitch-Modus sieht er, dass Schalter B kaputt ist.
Er muss die richtigen Schalter einschalten.

Lösung:
A = AN
B = AUS
C = AN

Wenn die Schalter richtig sind, ist das Rätsel gelöst.

Ablauf Spiel

Der Spieler startet das Spiel.
Die Zeit beginnt zu laufen.
Er sucht die drei Rätsel im Raum.
Er benutzt den Glitch-Modus, um Hinweise zu finden.
Er löst alle drei Rätsel.
Die Tür geht auf und er gewinnt.
Wenn die Zeit vorbei ist, hat er verloren und muss neu starten.
