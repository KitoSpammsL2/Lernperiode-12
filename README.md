# Lernperiode-12

## GLITCH - Escape the Simulation

In der Lernperiode 12 entwickeln wir als dreiköpfiges Team ein eigenes Browser-Game namens **GLITCH – Escape the Simulation**.

Bei unserem Spiel befindet sich der Spieler in einer kaputten digitalen Simulation, aus der er entkommen muss. Um den Ausgang zu erreichen, muss er verschiedene Rätsel lösen, versteckte Hinweise finden und mit unterschiedlichen Objekten interagieren.

Das Besondere an unserem Spiel ist der **Glitch-Modus**. Durch das Aktivieren dieses Modus verändert sich die Spielumgebung und Hinweise werden sichtbar, die normalerweise versteckt sind. Diese Hinweise helfen dem Spieler dabei, die Rätsel zu lösen und neue Bereiche freizuschalten.

### Unser Ziel

Innerhalb der ersten vier Wochen möchten wir ein funktionierendes MVP entwickeln. Dieses soll einen spielbaren Raum mit drei Rätseln, einem Countdown-Timer und dem Glitch-Modus enthalten.

Bis zum Ende der Lernperiode möchten wir das Spiel auf insgesamt fünf Levels erweitern. Zusätzlich planen wir ein Inventarsystem, eine Speicherfunktion und eine Anzeige der persönlichen Bestzeiten.

### Technische Umsetzung

Wir entwickeln das Spiel mit **HTML, CSS und JavaScript**. HTML verwenden wir für die Struktur, CSS für das Design und die Animationen und JavaScript für die Spiellogik und die interaktiven Funktionen.

Für die gemeinsame Entwicklung verwenden wir **GitHub**. Jedes Teammitglied übernimmt eigene Arbeitspakete und arbeitet an unterschiedlichen Bereichen des Spiels.
